Schemes, standards, and open-source code that go alongside my research — mostly proof-of-concept implementations released with a paper.

<ul class="project-list">
  <li>
    <a class="project-name" href="/projects/sdith/">SDitH</a>
    <div class="project-desc">A NIST PQC Round 3 candidate for the additional digital signatures process, based on the syndrome decoding problem.</div>
  </li>
  <li>
    <a class="project-name" href="/projects/online-offline-signatures/">Online/Offline Signatures</a>
    <div class="project-desc">A proof-of-concept implementation of post-quantum online/offline signatures, with cross-platform benchmarks.</div>
  </li>
  <li>
    <a class="project-name" href="/projects/sdith-in-hardware/">SDitH in Hardware</a>
    <div class="project-desc">A hardware implementation (in progress) of the Syndrome Decoding in the Head (SDitH) post-quantum signature scheme.</div>
  </li>
  <li>
    <a class="project-name" href="/projects/sandwich/">Sandwich</a>
    <div class="project-desc">An open-source, multi-platform, multi-language library providing a unified API over multiple cryptographic libraries.</div>
  </li>
  <li>
    <a class="project-name" href="/projects/falcon-fpu/">Falcon on Cortex-M7</a>
    <div class="project-desc">Benchmarking code for NIST PQC finalist lattice-based signature schemes on the ARM Cortex-M7.</div>
  </li>
  <li>
    <a class="project-name" href="/projects/saga/">SAGA</a>
    <div class="project-desc">A statistical test suite for verifying the correctness of univariate and multivariate Gaussian samplers used in lattice-based cryptography.</div>
  </li>
  <li>
    <a class="project-name" href="/projects/dilithium-forgery/">Dilithium Fault Attack</a>
    <div class="project-desc">Source code for a practical fault-attack forgery on the Dilithium lattice-based signature scheme, targeting pqm4 implementations of NIST candidates.</div>
  </li>
  <li>
    <a class="project-name" href="/projects/glitch/">GLITCH</a>
    <div class="project-desc">An earlier discrete Gaussian sampler testing suite for lattice-based cryptography, since superseded by SAGA.</div>
  </li>
</ul>
